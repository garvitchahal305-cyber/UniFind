UniFind – University Lost & Found
CampusFind is a simple website that helps students report and find items lost on campus.
Features
- Browse lost and found item cards.
- Search by item name or location.
- Filter listings by category and status.
- Report a lost or found item using the form.
- Mark items as resolved.
- Save listings in browser local storage.
Technologies
- HTML: Page structure
- CSS: Colours, layout and design
- JavaScript: Search, filters, form and storage
